# Phase 8: Study plan and dashboard

Phase 8 adds an offline dashboard driven entirely by the progress and review data stored on the device.

## Included

- A home dashboard showing today's chapter goal, total syllabus progress, and due reviews.
- A continue action that opens the next unread chapter.
- A review action that opens the oldest due chapter quiz.
- A study-plan screen with a daily goal from one to five chapters.
- A due-review list linked to the existing spaced-repetition schedule.

The daily goal is saved in app preferences. No account, connection, or background service is required.
