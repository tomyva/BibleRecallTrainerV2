# Phase 5: Deterministic quizzes

Phase 5 adds a local missing-word quiz to each chapter. Questions are derived directly from canonical bundled WEB verses: the quiz deterministically selects verses, removes one existing word, and asks the user to type it.

No Bible facts, distractors, summaries, or explanations are generated. The canonical content files remain unchanged. Answer checking is local and ignores letter case, common punctuation, and straight/typographic apostrophe differences.

Each quiz contains up to five questions and reports a transparent correct-answer count and percentage. It is a recall exercise, not a measure of theological understanding.
